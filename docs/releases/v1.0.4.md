# LAVOCADO v1.0.4

## Changes

- Switch the application from BSL 1.1 to AGPL-3.0-only to distribute with the
  existing AGPL dependencies. Personal and commercial use are permitted under
  AGPL; source-sharing requirements apply. Paid support and services remain possible.
- Exclude the unused Polars native runtime from Windows/macOS packages.
- Bound ONNX and PyTorch CPU inference to two threads by default and OpenCV to one.
- Disable ONNX worker spinning between screen checks.
- Reduce native screen capture from 30 to 10 FPS; existing inference scan intervals,
  model weights, detection thresholds, region verification and four model options
  are retained. Capture sampling can add up to about 100 ms before a fresh frame.
- Include license texts, model notices, exact dependency inventories and source
  archives; expose license/source information in the dashboard and installer.

Actual CPU usage depends on the device, screen activity and enabled models. This
release does not promise a fixed percentage reduction on users' machines.

## Downloads

Windows x64: installer or portable ZIP. macOS: Apple Silicon ZIP built on the
GitHub-hosted macOS runner. Builds are unsigned; macOS is not notarized.
The website's download buttons resolve to the latest published GitHub Release.
